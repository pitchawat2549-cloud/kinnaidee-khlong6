# กินไหนดีคลองหก

เว็บแนะนำร้านอาหารรอบ มทร.ธัญบุรี (ต.คลองหก อ.คลองหลวง จ.ปทุมธานี)
เก็บข้อมูลร้านในฐานข้อมูล **Supabase** (PostgreSQL) มีหน้าแอดมินสำหรับเพิ่ม แก้ไข ลบร้าน และอัปโหลดรูป

---

## ฟีเจอร์

**ฝั่งผู้ใช้**
- ค้นหาร้านจากชื่อร้าน ชื่อเมนู หรือชื่อซอย (ผลขึ้นทันทีขณะพิมพ์)
- กรองตามหมวด พื้นที่ งบต่อมื้อ ร้านที่เปิดอยู่ตอนนี้ และร้านที่ถูกใจ
- เรียงแบบสุ่ม (ค่าเริ่มต้น ทุกร้านได้ขึ้นก่อนเท่ากัน) / ชื่อ ก-ฮ / ราคา / ร้านที่เปิดอยู่ก่อน
- ป้าย "เปิดอยู่ / ปิดแล้ว" คำนวณจากเวลาจริง (รองรับร้านที่ปิดหลังเที่ยงคืน)
- ปุ่ม "กินอะไรดี?" สุ่มร้านตามงบและหมวด
- กดรูปดูเต็มจอ เลื่อนดูรูปถัดไปได้ (ปุ่มลูกศร / ปัดบนมือถือ / คีย์บอร์ด)
- เก็บร้านที่ถูกใจไว้ในเครื่อง (ไม่ต้องสมัครสมาชิก)
- แชร์ลิงก์ร้าน, ปุ่มโทรหาร้าน, ปุ่มนำทางด้วย Google Maps
- แจ้งข้อมูลผิด / แนะนำร้านใหม่ ส่งเข้าฐานข้อมูลให้แอดมินอ่าน
- ทุกตัวกรองอยู่ในลิงก์ เช่น `restaurants.html?cat=rice&open=1` ส่งต่อให้เพื่อนได้

**ฝั่งแอดมิน** (`admin/login.html`)
- ล็อกอินด้วยอีเมล / รหัสผ่าน
- เพิ่ม แก้ไข ลบร้าน ซ่อนร้านชั่วคราว
- อัปโหลดรูป เรียงลำดับรูป ใส่คำอธิบายรูปและที่มาภาพ
- พิมพ์เมนูเป็นข้อความธรรมดา ระบบแปลงเป็นตารางให้
- อ่านข้อความจากผู้ใช้ กด "ทำแล้ว" ได้

## โครงสร้างไฟล์

```
kinnaidee/
├── index.html                  หน้าแรก
├── restaurant/
│   ├── restaurants.html        รวมร้าน (ค้นหา / กรอง)
│   ├── detail.html             รายละเอียดร้าน (?id=รหัสร้าน)
│   └── favorites.html          ร้านที่ถูกใจ
├── about/about.html            เกี่ยวกับเรา
├── admin/
│   ├── login.html              เข้าสู่ระบบผู้ดูแล
│   └── index.html              จัดการร้าน
├── css/                        common.css ใช้ทุกหน้า + ไฟล์ของแต่ละหน้า
├── js/
│   ├── config.js               ★ ใส่ค่า Supabase ที่นี่
│   ├── api.js                  ตัวกลางดึงข้อมูล (Supabase หรือข้อมูลสำรอง)
│   ├── seed-data.js            ข้อมูลสำรอง ใช้ตอนยังไม่เชื่อมฐานข้อมูล
│   ├── ui.js                   ส่วนที่ทุกหน้าใช้ร่วมกัน
│   └── home.js, restaurants.js, detail.js, favorites.js, about.js, admin.js
├── supabase/
│   ├── schema.sql              สร้างตาราง + สิทธิ์ + ที่เก็บรูป
│   └── seed.sql                ข้อมูลร้านเริ่มต้น 9 ร้าน
└── images/                     รูปร้าน / ไอคอน / รูปตกแต่ง
```

ถ้ายังไม่ได้ตั้งค่า Supabase เว็บก็ยังใช้งานได้ โดยดึงข้อมูลจาก `js/seed-data.js` แทน
(แต่ส่งข้อความแนะนำร้าน และหน้าแอดมิน จะใช้ไม่ได้จนกว่าจะเชื่อมฐานข้อมูล)

## ตั้งค่าฐานข้อมูล Supabase (ทำครั้งเดียว ประมาณ 10 นาที)

1. **สมัคร / สร้างโปรเจกต์**
   ไปที่ https://supabase.com → Sign in ด้วย GitHub → **New project**
   ตั้งชื่อ `kinnaidee`, ตั้งรหัสผ่านฐานข้อมูล, Region เลือก **Southeast Asia (Singapore)** → Create

2. **สร้างตาราง**
   เมนูซ้าย **SQL Editor** → New query → วางเนื้อหาทั้งไฟล์ `supabase/schema.sql` → **Run**
   จากนั้น New query อีกครั้ง → วาง `supabase/seed.sql` → **Run** (ได้ร้านเริ่มต้น 9 ร้าน)

3. **ปิดการสมัครสมาชิก** (สำคัญ ไม่งั้นใครก็สมัครแล้วแก้ร้านได้)
   **Authentication → Sign In / Providers** (หรือหน้า Auth settings) → ปิด **Allow new users to sign up**

4. **สร้างบัญชีแอดมิน**
   **Authentication → Users → Add user → Create new user**
   ใส่อีเมลและรหัสผ่านของคนที่จะดูแลเว็บ ติ๊ก **Auto Confirm User** → Create

5. **ใส่ค่าในเว็บ**
   **Project Settings → API** คัดลอก **Project URL** และ **anon public key**
   เปิด `js/config.js` แล้วใส่:
   ```js
   window.APP_CONFIG = {
     SUPABASE_URL: "https://xxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGciOi..."
   };
   ```
   anon key ใส่ในเว็บได้ ไม่อันตราย เพราะสิทธิ์ถูกคุมด้วย Row Level Security ใน `schema.sql`
   (ห้ามใส่ **service_role key** เด็ดขาด)

6. **อัปโหลดขึ้น GitHub** แล้วเปิดเว็บ ลองเข้า `admin/login.html` ด้วยบัญชีจากข้อ 4

## เพิ่มร้านใหม่

**หลังเชื่อม Supabase แล้ว:** เข้า `admin/login.html` → **+ เพิ่มร้านใหม่** กรอกข้อมูล อัปโหลดรูป → บันทึก
หน้าเว็บอัปเดตทันที ไม่ต้องแก้โค้ด

**รูปแบบที่อยู่ (ใช้เหมือนกันทุกร้าน)**
| ช่อง | ตัวอย่าง |
|---|---|
| ที่อยู่ (เลขที่ / ซอย / ถนน) | `12/3 ซอยพรธิสาร 3 ถนนรังสิต-นครนายก` |
| จุดสังเกต | `ตรงข้ามร้านเอสโตว์ ห่างประตูหน้า มทร. 200 ม.` |

ระบบต่อท้าย `ต.คลองหก อ.คลองหลวง จ.ปทุมธานี 12110` ให้อัตโนมัติ
เวลาเปิด-ปิดเลือกจากช่องเวลา ระบบแสดงเป็น `10:00 - 21:00 น.` ให้เอง

**รูป:** ไม่เกิน 5 MB ต่อรูป ควรเป็นแนวนอน รูปแรกคือรูปหน้าปก ต้องใส่ "ที่มาภาพ" ทุกครั้ง

## ข้อควรรู้

- **ร้านที่ถูกใจ** เก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่ได้เก็บในฐานข้อมูล ล้างข้อมูลเบราว์เซอร์แล้วจะหาย
- **Supabase แบบฟรี** หยุดชั่วคราวถ้าไม่มีคนใช้ 7 วัน เข้าไปกด Restore ในหน้า Supabase ก่อนนำเสนอ
- **รูปตกแต่งและไอคอน** มาจาก Canva ใช้เพื่อการศึกษาเท่านั้น
